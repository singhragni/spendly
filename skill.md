Generates modern, production-ready UI components and pages for the Sprendly expense tracker.

Clean and responsive design
Consistent with fintech-style UI
Uses meaningful icons
Focuses on usability and clarity

“Design the … page”
“Create UI for …”
“Build component for …”
“Redesign / improve …”

(Especially for Sprendly-related UI requests)

Page or component name
Optional:
Constraints
Data
References

📤 Output Should Include
1. UI Structure (Brief)
Layout and key sections
Important UX decisions
2. Code
Clean CSS / Tailwind (if applicable)
Modular components
Minimal boilerplate
3. Design Quality
Modern SaaS look
Good spacing and hierarchy
Card-based layout
Subtle colors and shadows
4. Icons

Minimal, clean fintech-style UI
Rounded corners, soft shadows
Consistent spacing (8px grid)
Avoid clutter and random styles


🔁 Consistency Rules
Match existing project design
If unclear → ask for reference/screenshots


❌ Avoid
Generic or outdated UI
Unstructured code dumps
